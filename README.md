# 🚲 Bike Sharing Network Performance Analysis Using Power BI

## 📌 Project Overview

This project presents an interactive Power BI dashboard developed to analyze the operational performance of a public bike-sharing network. The dashboard provides insights into bike availability, station status, bike stand capacity, and contract-wise performance using Excel, Power Query, and DAX.

---

## 🎯 Objectives

- Analyze bike-sharing station performance.
- Monitor station operational status.
- Evaluate bike availability across contracts.
- Build interactive dashboards for business insights.
- Support data-driven operational decisions.

---

## 📂 Dataset

The dataset contains operational information about bike-sharing stations, including:

- Station ID
- Station Name
- Address
- Contract Name
- Status
- Bike Stands
- Available Bike Stands
- Available Bikes
- Banking
- Bonus
- Last Update

## 📈 Key KPIs

## 💡 Key Insights

- Most bike stations are operational.
- Bike availability differs across contracts.
- Operational status can be monitored using KPI cards.
- Interactive filters enable contract-level analysis.
- Dashboard supports monitoring of bike-sharing operations.
